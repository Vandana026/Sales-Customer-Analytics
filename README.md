# Sales & Customer Analytics Dashboard

## Project Overview

This project analyzes the Olist Brazilian E-Commerce Dataset and provides business insights into sales performance, customer behavior, product performance, and delivery operations.

The project was built using Python, SQL, Power BI, and DAX to simulate a real-world Data Analyst workflow.

## Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* SQL (SQLite)
* Power BI
* DAX
* Git & GitHub

## Dataset

Source: Olist Brazilian E-Commerce Dataset (Kaggle)

Files Used:

* olist_orders_dataset.csv
* olist_customers_dataset.csv
* olist_order_items_dataset.csv
* olist_products_dataset.csv
* olist_order_payments_dataset.csv

## Project Workflow

### 1. Data Cleaning

* Handled missing values
* Converted date columns
* Removed data quality issues

### 2. Data Integration

* Merged customers, orders, products, order items, and payments data
* Built a master analytics dataset

### 3. Feature Engineering

Created:

* Revenue
* Purchase Year
* Purchase Month
* Purchase Quarter
* Month-Year
* Delivery Days
* Delivery Status

### 4. Exploratory Data Analysis

Analyzed:

* Revenue trends
* Customer behavior
* Product performance
* Payment methods
* Regional sales

### 5. Customer Segmentation (RFM)

Customer segments:

* Champions
* Loyal Customers
* Potential Loyalists
* At Risk
* Lost Customers

### 6. SQL Business Analysis

Business queries included:

* Top states by revenue
* Revenue by category
* Monthly revenue trends
* Customer spending analysis
* Delivery performance

### 7. Power BI Dashboard

Pages:

1. Executive Overview
2. Customer Analytics
3. Product Analytics
4. Delivery & Operations Analytics

## Key Business Insights

* São Paulo generated the highest revenue.
* Loyal and Champion customers contributed significantly to total sales.
* Most orders were delivered on time.
* A small number of categories drove a large share of revenue.
